# Bull Superski glide project - all tests

Source: https://bullsuperski.no/glidprosjektet/ (18 reports, Jan 2025 - Mar 2026, transcribed from the report images). Rebuild with `python3 build_tables.py`.

## How placings are scored

The reports rank only the top 3; the rest are listed as "also tested". So each result is scored **3 points for 1st, 2 for 2nd, 1 for 3rd, 0 for tested but off the podium**. Combinations (e.g. `Swix PS6 + Toko HP Blue`) give their points to every product in them. Per product this gives:

- **Points per test** - average points when the product was in the test (0-3).
- **Podium rate** - share of its tests where it finished top 3.
- **Condition-class points** - points split into A cold/dry, B medium/transformed, C wet.

Condition classes: A: Cold / dry (snow <= -4.5C or <25% humidity); B: Medium / transformed (25-55% humidity, snow -4 to 0C); C: Wet (>=55% humidity, snow ~0C).

## Predicting a race day in Holmenkollen

`predict.py` weights every past test by how close its snow temperature and snow humidity are to the forecast and returns the products with the highest expected placing points:

```
python3 predict.py --snow-temp -2 --humidity 35
python3 predict.py --air-temp 4 --humidity 70   # snow temp estimated from air
```

Snow humidity (snøfukt) is the strongest separator in this data, so measure or estimate it if you can. Treat the output as a short list to test, not a guarantee: there are only 18 tests, gaps between the top 3 are often described as small, and the product line-up changes from test to test.
